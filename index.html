03 — Projects

From architecture to handoff

Enpal · Make.com middleware

Talkdesk–Azure call middleware

Designed and deployed the integration that sits between the contact center and Azure. A finished call arrives on a webhook. The scenario waits for the recording, reuses a cached OAuth token or requests a new one, retrieves the audio, transcribes it, and posts one normalized payload to Azure.

04 — Integrations

Systems I connect

Make.com · Talkdesk · Azure

Call events into Azure

Webhook in, authenticated API out. Call context, agent, queue, duration, and the recording link travel as one payload, and the audio file is transcribed.

Talkdesk · OAuth

Token lifecycle

Client-credentials tokens are stored and reused. When the stored token is missing or expired, the scenario requests a new one before it calls the Recordings API.

Azure AD · Talkdesk

SAML single sign-on

Centralized Talkdesk login through Microsoft Azure AD, so access follows the company identity instead of a separate password.

Salesforce · Talkdesk · Airtable

Contact-center connections

CTI, data dips, and operational integrations across Salesforce and Airtable, including the Talkdesk–Azure speech-to-text architecture.
